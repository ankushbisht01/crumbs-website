# Crumbs & Co. — Bakery Website

This website for Crumbs & Co., a made-up bakery, is built by a whole class during a Git & GitHub workshop.
Nothing on this site is real: every name, price, date and code is invented.

## How to contribute

You cannot push to this repository. Contribute through a fork and a pull request:

1. **Fork** this repository (button at the top right).
2. **Clone your fork**: `git clone https://github.com/<your-username>/crumbs-website.git`
3. Add this repository as `upstream`:
   `git remote add upstream https://github.com/ankushbisht01/crumbs-website.git`
4. Create a branch: `git switch -c group<GG>-slot<SS>`
5. Edit **only** `pages/group-<GG>.html`, and **only** between your own `SLOT <SS>` markers.
6. Commit, then push to **your fork**: `git push origin <your-branch>`
7. Open a pull request into `main` of this repository.

## Rules

- Never edit outside your own slot (except the intro line in Level 5).
- Never delete or rewrite anyone else's work.
- Never force-push.

Pull requests that change more than one file, or delete other people's lines, are not merged.
